# Internet Genesis

Браузерная игра про зарождение интернета. Работает без сборки, только HTML, CSS и JavaScript.

## Запуск
Открой `index.html` двойным кликом в браузере.


## Что где лежит
| Файл | Что внутри |
|---|---|
| `index.html` | разметка и порядок подключения скриптов |
| `style.css` | оформление, темы и анимации |
| `js/data.js` | все числа и таблицы: модули, комплектующие, детали, контент, технологии |
| `js/state.js` | состояние игры, сохранение и загрузка |
| `js/rules.js` | правила: работают ли деталь, комплектующее, сервер |
| `js/sim.js` | сеть, зона роутера, электричество, доход |
| `js/map.js` | карта: камера, узлы, порты, связи, рисование |
| `js/windows.js` | окна: сервер, комплектующее, дерево технологий, офис, поломки, контент |
| `js/menu.js` | достижения, магазин, сохранения, тема, режим разработчика |
| `js/actions.js` | действия игрока |
| `js/ui.js` | палитра, окно выбора узлов, панели |
| `js/main.js` | игровой цикл и запуск |

Скрипты подключаются по порядку и делят одни и те же глобальные переменные, поэтому порядок в `index.html` менять нельзя.
